# Agent — карманный AI-агент-кодер (Android)

Агент в духе opencode / claude code, но в виде Android-приложения: чат с LLM,
автономный цикл работы с инструментами (файлы + shell) в воркспейсе на телефоне.

## Возможности
- Чат с агентом, стриминг ответа в реальном времени
- Автономный агентный цикл: модель сама вызывает инструменты до выполнения задачи (до 20 шагов)
- Инструменты: `list_files`, `read_file`, `write_file`, `delete_file`, `run_shell`
- **История чатов**: каждый чат сохраняется автоматически, можно открыть или удалить (`История`)
- **Выбор папки**: воркспейсом может быть любая папка на телефоне — кнопка `Папка` (системный выбор папки); по умолчанию — встроенная папка приложения. В режиме выбранной папки shell-инструмент недоступен (ограничение Android SAF), файлы работают
- **Аккаунт и API ключи — раздельно**:
  - `Аккаунт` — выбор активного провайдера (Gemini / OpenCode / OpenAI-совместимый), вставка ключа, кнопка «Получить ключ» открывает сайт провайдера
  - `API ключи` — отдельные поля ключей/моделей/base URL для всех провайдеров сразу
- Провайдеры: **Google Gemini** (aistudio.google.com/apikey), **OpenCode** (`https://opencode.ai/zen/v1`), любой **OpenAI-совместимый API**
- API-ключи хранятся в `EncryptedSharedPreferences` (шифрование ключом устройства)

## Установка
1. Скачай APK из папки [releases](releases) (или из артефактов сборки GitHub Actions)
2. Разреши установку из неизвестных источников и установи
3. Открой приложение → `Аккаунт` → выбери провайдера → «Получить ключ» → вставь ключ → `Подключить`
4. (Опционально) `Папка` — выбери папку воркспейса
5. Пиши задачу агенту

## Сборка из исходников
```bash
./gradlew assembleRelease
```
APK: `app/build/outputs/apk/release/app-release.apk`.
GitHub Actions собирает APK автоматически при каждом пуше в `main`.

Для подписи своим ключом положи в корень `keystore.properties`:
```
storeFile=agent.keystore
storePassword=...
keyAlias=agent
keyPassword=...
```
Без него release собирается с debug-подписью (устанавливается на устройство).
